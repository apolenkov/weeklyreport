## Why

The installed shared Zod validator counts Unicode code points. Current web counters count UTF-16 units, and Item next-step/pause and reopen-reason guards reject a schema-valid 500-point non-BMP value. Actual public DOM tests reproduce wrong counts, invalid field state and blocked Save/Send. C5098 owns the shared metric correction; other V29 original claims retain their separate evidence boundaries.

## What Changes

- Match the three current counters and the two proven producer guards to the existing schema metric using standard string iteration.
- Preserve numeric limits, raw versus trimmed validation placement, required/null behavior, all pending/parent/stage/status rules and complete over-limit drafts.
- Reuse SI01's exported invisible-text message in the existing classifier with identical bytes and behavior.
- Keep native `maxlength`, padding, focus chronology, assistive-technology and persistence acceptance open; no native policy changes.
