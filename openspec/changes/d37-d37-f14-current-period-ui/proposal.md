# Proposal

## Why

Current public UI controls lose numeric help, move focus during correction, accept an empty deadline time, and expose frozen date edits. Period choices also react to secondary presses and exceed the vertical viewport. Latest-query reporting, reminder transport copy and history streak text need to follow their existing owners. D37-F14's selected cards and genuine component RED receipts identify these roots.

## What Changes

Repair these current UI-state consumers; reuse canonical route constants and presentation contracts without changing URLs or glyphs. Preserve already-fixed manual range, Head history projection and pipeline rationale.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `client-error-policy`: apply the existing query failure seam to Latest.
- `admin-settings-ui`: clarify active time validity, persistent numeric descriptions and correction focus.
- `dialog-listbox-a11y`: clarify primary/click activation and vertical viewport bounds.
- `lead-history-summary`: use status/recency-neutral one-period streak text.
- `period-scheduler-wiring`: expose the existing frozen-envelope rule in the editor.

## Impact

Assigned Web owners and existing colocated tests. No schema, API, dependency, authorization or runtime-resource changes.

## Non-goals

Native number-input policy without its required supported-browser proof; speculative skeleton geometry; Decision malformed-date repair without an admitted producer; whole/native/canonical acceptance from unit evidence.
