## Why

F19 current consumers retry only one failed Trends dependency, show an unresolved History role subtitle, select Activity empty copy from archived rows, repeat error toasts before recovery, and omit two required client error handlers. Navigation constants and dev-login URL construction have duplicated owners.

## What Changes

- Retry each failed Period comparison dependency independently.
- Hold the role subtitle until session resolution and distinguish an active-list filter from archived data.
- Preserve complete archived Activity names by wrapping them beside Restore.
- Log each new query failure, toast once until success, and report Head active and dev users load failures through the existing seam.
- Cancel search result mousedown's focus default so result click can navigate.
- Derive home routes from the existing shared map, reuse lead/viewer route constants, type repeated print jobId input, and give dev-login URL encoding one pure owner while retaining each caller's redirect policy.
- Retain the shared global print-color policy and remove its duplicate template declaration.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `client-error-policy`: one toast per error episode; active Head and dev users reporting.
- `lead-history-summary`: role subtitle waits for the session.
- `trends-query-window`: one Retry refreshes each failed comparison dependency.
- `list-empty-state-fidelity`: active Activity empty-state filter and archived-name containment.
- `web-shared-idioms`: dev-login encoding owner and home/lead/viewer route reuse.
- `route-query-normalization`: repeated print jobId treated as absent.

## Impact

Only F19 granted web owners and its unique OpenSpec change. Existing Sentry monotonic/headers, Activity logging and login fallback are reused. Chevron geometry and History toolbar sizing are untouched pending native RED; navigation cancellation remains needs-evidence pending measured policy. Root owns native browser, full gates, review and publication. Source checkpoint is not canonical ticket closure.
