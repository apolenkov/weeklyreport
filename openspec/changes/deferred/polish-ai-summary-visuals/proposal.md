# Polish AI summary visuals

## Problem

The AI summary "unavailable" state has visual inconsistencies — corner radius
does not match the rest of the component, making it feel disconnected from the
design system.

## Solution

Audit the AI summary component visuals (corners, spacing, background color,
border) and align them with the design system tokens. Fix corner radius mismatch
and ensure the unavailable state integrates seamlessly.

## Non-goals

- Add new AI summary features.
- Change the availability logic or API.
- Redesign the entire AI summary layout.

## Source

User observation: visual polish gap noted during Phase 61+ design audit.

## Activation trigger

Activate when AI summary feature is fully activated in the product or when
visual polish sprint is planned.
