## Why

Current isolated API test adapters can expose stored feedback through shared references and silently hide expired Redis keys or missing Lua scripts. Denied search loses its safe domain cause identity. F06 also owns specific repeated lifecycle/actor/endpoint declarations and obsolete private parameters; previously shipped fixes are preserved.

## What Changes

- Repair only admitted memory-copy, Redis expiry/NOSCRIPT and safe search-cause boundaries after genuine public-owner RED.
- Derive editable lock/query/assignment projections from one lifecycle declaration while preserving each existing date policy.
- Reuse one exact actor whitelist and Mailpit messages URL; remove only the assigned dead stub parameter and absent auth RPC exemption.

## Non-goals

No shared schema, authorization, lifecycle dates, new auth procedures, general Redis emulator, Mailpit nullable-recipient/deadline policy, generic Nest object serializer, API/private data or dependency changes. Main specs, native/API/PG/collector acceptance and aggregate review remain Root-owned.

## Impact
