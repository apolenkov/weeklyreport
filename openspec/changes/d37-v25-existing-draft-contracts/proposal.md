# Proposal

## Why

The existing lead draft paths can hide an available foreign risk author, mutate
resolved work through section callbacks, lose a stage update within one React
batch, and reject an Overview parent change despite showing its sole stage as
automatically applied. D37-V25's brief identifies the existing source paths;
owner regressions must reproduce each selected correction before implementation.

## What Changes

- Choose a named foreign covering contributor when one is available.
- Apply move, complete and pause intents against the latest raw item and reuse
  the existing move eligibility rules.
- Preserve existing functional product updaters to the latest raw draft boundary.
- Apply the existing single-stage selection rule when Overview changes parent.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. These repairs preserve existing contracts rather than selecting new
requirements. `skip_specs: true` records the absence of spec deltas.

## Impact

Affected owners are the item card derivation, lead draft command adapter and
patch boundary, sync bridge and its explicitly transferred Overview callback
type, and Overview plan composer. Existing tests remain the test owners.

Owning contracts: `record-status-derivation` (foreign attribution),
`lead-form-draft-merges` (current raw draft and item identity),
`unified-report-authoring` (resolved work and editable parent scope), and
`stage-step-shared-component` (shared stage selection). The hook's existing
functional updater contract independently requires latest-state application.

## Non-goals

- Change server schemas, authorization, lifecycle or outcome restoration.
- Define an ordering among named authors, new palette or input policy.
- Declare native browser, Safari, AT, persistence or autosave-loss acceptance.
- Add unmeasured memoization, pending locks or new debounce/version policies.
- Fabricate an author when every covering contributor is nameless.
