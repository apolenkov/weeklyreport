Полное или shard-продолжение остаётся отдельным контуром NOT-PROVEN.
  3. 5.17 · исследование ёмкости · ACCEPTED-BOUNDED На историческом exact-source initial preflight guard сохранил границу 8199 > 8192. Последующий single-child survey с допуском 65536 controls истёк по стене 600000ms и не создал terminal result. Пакет принят только как диагностический; лимит нельзя менять по этому числу.
  4. 5.19 · source-bound canonicalization · CODE-PARTIAL / CANARY NOT-PROVEN На странице Action Log seed показывает 20 loaded+ строк, а каждая ActionLogRow хранит независимый useState(false) для раскрытия деталей. Несколько раскрытий одновременно дают аддитивный powerset-граф: при maxDepth=4 это уже 1+20+190+1140+4845=6196 reachable subsets. Это показывает рост harness-графа, но не разрешает trim и не устанавливает root cause. Введён source-bound контракт data-reveal-independence="source-bound-row-local" для row-local disclosure; без него даже pairwise-commutative triple остаётся ordinary branch. Исторический code candidate сохраняет target-based sequence identity, reversible pair-order proof, material-union guard и boundary rejection для trusted A/B/C + untrusted fourth disclosure. Exact admin/demo canary на новом clean source ещё не запускался: он требует source-bound browser/API/DB/Redis/telemetry packet и независимое Sol review. Поэтому лимит нельзя повышать, граф нельзя обрезать, а 5.19 нельзя помечать закрытым по одним тестам.
  5. Полная матрица · после causal boundary Манифест 6.1 уже заморожен исторически. Сначала связать его с текущим exact source и обновлёнными runtime-contracts, затем выполнить заявленную матрицу, импортировать независимые пакеты, разобрать находки, исправить подтверждённые пробелы и повторить полный и затронутый affected/full sweep на одном финальном SHA доказательств исполнения.

5. Правила продолжения

  • Любая правка исходника продукта, исполнения или стенда делает десктопный пакет историческим; съёмку и проверку нужно привязать к новому точному SHA.
  • Допустим только прямой потомок с изменениями лишь в метаданных, если отдельная проверка докажет, что он не меняет продукт, сборку, seed, стенд, исполнение или поведение развёртывания.
  • OpenSpec и частный backlog остаются источниками истины для состояния задач; эта HTML-страница является только проекцией для владельца.
  • Ограниченные runtime/browser/DB/Redis-пакеты уже выполнены только на allowlisted disposable target; production, внешняя публикация и неизвестные базы не затрагивались.
