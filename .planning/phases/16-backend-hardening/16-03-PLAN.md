Add import for ThemeProvider from next-themes. Note: next-themes is a dependency of `@customreport/ui` which is already installed. Import directly from 'next-themes':
```typescript
import { ThemeProvider } from 'next-themes';
```

Wrap all body children with ThemeProvider per D-11 (system detection) and D-12 (cookie persistence):
```tsx
<html lang="ru" className={`${GeistSans.variable} ${GeistMono.variable}`} suppressHydrationWarning>
  <body className="min-h-svh bg-background font-sans antialiased">
    <ThemeProvider attribute="class" defaultTheme="system" enableSystem disableTransitionOnChange>
      <TooltipProvider>
        <TRPCProvider>{children}</TRPCProvider>
      </TooltipProvider>
      <Toaster position="bottom-right" richColors closeButton />
    </ThemeProvider>
  </body>
</html>
```

Key props explained:
- `attribute="class"` -- adds `dark` class to `<html>` for Tailwind dark mode
- `defaultTheme="system"` -- per D-11, detect OS preference
- `enableSystem` -- per D-11, enable system preference detection
- `disableTransitionOnChange` -- prevents FOUC flash (Pitfall 4)

Note: `suppressHydrationWarning` is already on `<html>` tag (required by next-themes).
