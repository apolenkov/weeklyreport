Output: Six controlled admin tabs whose every save/delete button is a real mutation with cache invalidation and toast feedback.

Mutation pattern (re-used from 22-01):
```ts
const trpc = useTRPC();
const qc = useQueryClient();
const saveUserMut = useMutation(trpc.admin.saveUser.mutationOptions({
  onSuccess: () => { invalidateAdmin(qc, trpc); toast.success('User saved'); setShowDialog(false); },
  onError: (err) => toast.error(err.message ?? 'Failed to save user'),
}));
saveUserMut.mutate({ id: editingUser?.id, ...formAsAdminUserInput });
```

Stage assignment editor: lives inside products-tab.tsx contextually (it edits which leads own which stages per project). Verify the integration point in products-tab.tsx and wire its mutations there or in stage-assignment-editor.tsx itself.
