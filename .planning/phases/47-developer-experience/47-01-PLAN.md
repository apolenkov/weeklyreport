# Phase 47-01 — docker compose watch

**Status:** ready
**Depends on:** none
**Requirement:** DX-01 (replace flaky `node --watch` with docker-supervised auto-restart)

## Goal

Make `docker compose up --watch` (compose v2.22+) the canonical dev-loop:
on any change to `apps/api/src/`, `apps/web/src/`, `packages/shared/src/`,
or `prisma/schema.prisma`, the appropriate container restarts within ~3
seconds. After this plan: dev does not have to remember `docker compose
restart` after long uptimes; the stale-container failure class is gone.

## Acceptance Criteria

- `docker-compose.dev.yml` declares a `develop.watch` block for both
  `api` and `web` services with `action: restart` and the four paths above.
- `package.json` root has a `dev:watch` script alias for
  `docker compose -f docker-compose.dev.yml up --watch`.
- README documents the new dev workflow (one-liner: «use `pnpm dev:watch`,
  not `pnpm dev`»).
- Edit-and-save smoke test: touching `apps/api/src/main.ts` triggers an
  api restart visible in `docker logs customreport-api-1` within 5s.
- `pnpm dev` (the legacy script) is NOT removed — kept for users who want
  the local node-only loop.
- No source-of-truth duplication: if `docker-compose.yml` (production)
  defines healthchecks or ports for api/web, do NOT copy those into the
  dev compose. The dev compose extends the prod one when it needs to.

## Steps

1. Verify compose version supports watch:

   ```bash
   docker compose version
   # expected: Docker Compose version v2.22.0 or newer
   ```

2. Edit `docker-compose.dev.yml`:
   - For the `api` service, add:

     ```yaml
     develop:
       watch:
         - action: restart
           path: ./apps/api/src
         - action: restart
           path: ./packages/shared/src
         - action: restart
           path: ./prisma/schema.prisma
     ```

   - For the `web` service, add:

     ```yaml
     develop:
       watch:
         - action: restart
           path: ./apps/web/src
         - action: restart
           path: ./packages/shared/src
     ```

3. Add to root `package.json` scripts:

   ```json
   "dev:watch": "docker compose -f docker-compose.dev.yml up --watch"
   ```

4. Update root README's "Local development" section: new preferred command,
   note that legacy `pnpm dev` (host-side processes) is still available.

5. Smoke test:

   ```bash
   pnpm dev:watch &
   sleep 10
   echo "// 47-01 watch test $(date +%s)" >> apps/api/src/main.ts
   sleep 6
   docker logs customreport-api-1 --since 10s | grep -i "restart\|starting"
   # expected: at least one restart line
   git checkout -- apps/api/src/main.ts
   ```

6. Update `feedback_docker_dev_stale_code.md` memory: note that after 47-01,
   the «container Up >12h» heuristic is obsolete in dev; only relevant
   for production / CI containers.

## Verification Commands

```bash
docker compose version
docker compose -f docker-compose.dev.yml config | grep -A 10 develop:
pnpm dev:watch  # starts the dev loop with auto-restart
```
