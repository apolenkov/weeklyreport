# Phase 17 Plan 05 — Wave 4: Dashboard + Weekly Report UI

## Objective

Build the Dashboard (central hub for Head role) and Weekly Report page,
matching mockup v14 slides 2 and 3.

## Requirements Closed

- **UI-05**: Dashboard — central hub with KPIs, Alert, Blocked & At Risk, Lead Reports, Archive
- **UI-06**: Dashboard — Lead Reports: own card clickable, others locked, traffic lights
- **UI-07**: Dashboard — Report Archive with pagination
- **UI-08**: Dashboard — Toggle All button
- **UI-09**: Weekly Report — auto-compiled, period nav, Publish & Lock, Export PDF
- **UI-10**: Weekly Report — per-lead accordions with full data

## Component Architecture

```
apps/web/src/components/dashboard/
  dashboard-page.tsx                — main layout orchestrator
  kpi-cards.tsx                     — Submissions, Deadline, Escalations
  alert-bar.tsx                     — "2 leads haven't submitted"
  blocked-at-risk-table.tsx        — products with blocked/at-risk counts
  lead-reports-grid.tsx            — 6 lead cards with status + traffic lights
  lead-report-card.tsx             — single lead card
  report-archive-section.tsx       — paginated archive cards
  toggle-all-button.tsx            — collapse/expand all sections

apps/web/src/components/weekly-report/
  weekly-report-page.tsx           — main layout
  portfolio-overview-table.tsx     — product × worst-case status
  lead-accordion.tsx               — expandable lead section
  lead-accordion-content.tsx       — items/risks/decisions/priorities
  escalations-section.tsx          — consolidated blocked + risks
  publish-lock-button.tsx          — Publish & Lock with confirmation
  export-pdf-button.tsx            — trigger PDF export
```

## Step 1 — Dashboard KPIs (UI-05)

### `kpi-cards.tsx`

Three cards in a row:
- **Submissions**: `4/6` with progress bar, green when complete
- **Deadline**: `2d 5h` countdown timer, yellow/red when approaching
- **Escalations**: count of blocked + at-risk items

Data source: tRPC `review.dashboard` + `report.weekly`.

## Step 2 — Alert Bar

### `alert-bar.tsx`

Yellow warning banner:
- "2 leads haven't submitted — Send Reminder"
- Shows only when submission count < total leads
- "Send Reminder" button triggers reminder flow

## Step 3 — Blocked & At Risk Table

### `blocked-at-risk-table.tsx`

Table columns: Product, Blocked Count, At Risk Count, Stages
- Rows sorted by severity (most blocked first)
- Stage indicators show which stages have issues
- Click row expands to show details

Data source: extracted from `report.weekly` escalations.

## Step 4 — Lead Reports Grid (UI-06)

### `lead-reports-grid.tsx` + `lead-report-card.tsx`

6 cards (one per lead):
- Lead name + department owner label
- Status badge: Submitted (green), Draft (yellow), Pending (gray)
- Traffic light dots: green/yellow/red counts from portfolio
- Own card: clickable, navigates to that lead's form view
- Others: locked icon, view-only on click
- "Revoke" button on submitted cards (head-only)

### Revoke flow:
1. Click "Revoke" → confirmation dialog
2. Call tRPC `leadSubmission.revoke`
3. Card status updates to "Draft"

## Step 5 — Report Archive (UI-07)

### `report-archive-section.tsx`

Paginated card grid:
- Month headers (April 2026, March 2026...)
- Week labels (Week 16, Week 15...)
- Status badges (Published/Draft)
- Click navigates to `/reports/[reportId]`
- "Load More" pagination

Data source: tRPC `archive.list`.

## Step 6 — Toggle All (UI-08)

### `toggle-all-button.tsx`

Single button that expands/collapses all accordion sections on the page.
Used on both Dashboard and Weekly Report.

## Step 7 — Weekly Report Page (UI-09)

### `weekly-report-page.tsx`

Layout:
- Period navigator (reuse from Wave 3)
- "Live · 4/6 Submitted" badge
- "Publish & Lock" button + "Export PDF" button
- Portfolio Overview table
- Per-lead accordion sections
- Escalations section

### Period navigator
Reuse `period-navigator.tsx` from Wave 3.

### Publish & Lock flow (ties to API-01):
1. Click "Publish & Lock" → warning dialog
   - If pending leads exist: "2 leads haven't submitted. Publish anyway?"
2. Call tRPC `period.publish`
3. Period status changes to "Published"
4. All forms lock

### Export PDF:
1. Click "Export PDF"
2. Call tRPC `pdfExport.request`
3. Show progress indicator
4. Download when complete

## Step 8 — Portfolio Overview Table

### `portfolio-overview-table.tsx`

Table: Product | Worst Status | Stages Affected | Contributing Leads
- Color-coded status chips (green/yellow/red)
- Sortable by status severity

Data source: `report.weekly` → portfolioOverview.

## Step 9 — Per-Lead Accordions (UI-10)

### `lead-accordion.tsx` + `lead-accordion-content.tsx`

Each lead has an expandable section:
- Header: lead name, product count, item/risk/decision counts
- Content grouped by section:
  - Current Week items (by product → stage)
  - Next Week items
  - Risks & Blockers
  - Decisions
  - Top 3 Priorities

Reuse item/risk/decision display components from Wave 3 (read-only variants).

## Step 10 — Escalations Section

### `escalations-section.tsx`

Consolidated list:
- Blocked stages (product + stage + lead)
- At-risk items (product + stage + severity)
- Unresolved risks (risk text + impact + product)

## Exit Criteria

1. Dashboard renders all 5 sections matching mockup s2
2. KPIs show real data (submissions count, deadline, escalations)
3. Lead Report cards show correct status + traffic light dots
4. Revoke button works with confirmation
5. Report Archive paginates correctly
6. Weekly Report compiles from submitted data matching mockup s3
7. Period navigator switches historical reports
8. Publish & Lock flow works end-to-end
9. Export PDF triggers async job
10. Per-lead accordions expand/collapse with full data
11. `pnpm typecheck` passes clean
