## Step 1 — API-04: Lead Request Reopen

### What

A lead can request that the head reopens their submitted section. This creates
a notification record (no real email — just a DB record the head can see on
the dashboard).

### Implementation

Extend `LeadFormService`:

```
requestReopen(sectionId: string, userId: string, reason?: string):
  Promise<{ success: true }>
```

Logic:

1. Verify caller is section author
2. Verify section is submitted
3. Create a `ReopenRequest` record (or use existing notification mechanism)
4. Return success

Add tRPC procedure `leadForm.requestReopen` (protectedProcedure, mutation).

### Files to modify

- `apps/api/src/modules/report-sections/lead-form.service.ts`
- `apps/api/src/modules/report-sections/lead-form.prisma-repository.ts`
- `apps/api/src/infrastructure/trpc/trpc.router.ts`

### Tests

- lead-form.contract.test.ts: add 2 tests (happy path, wrong author)

## Step 2 — API-11: Admin Settings CRUD
