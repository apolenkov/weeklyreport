<objective>
Migrate the Admin Panel (5 tabs sharing a single snapshot endpoint) and the Dashboard page (composed of 3 endpoints) from mock data to real tRPC queries. Mutations stay out of scope — Phase 22 wires Add/Edit/Delete buttons. This plan converts the read paths only.

Purpose: Admin and Dashboard share a structural property — both consume aggregate read endpoints (`admin.snapshot` returns everything for admin in one call; the dashboard composes 3 endpoints into a KPI view). Bundling them in one plan keeps the composite-mapper boilerplate (admin.ts + dashboard.ts) co-located and parallel-safe with 21-04 because the file sets do not overlap.

Output:

- `mapAdminSnapshot` composite mapper turning a single API call into the 5-tab data set, plus `mapAdminSettings`
- `mapDashboardData(reviewDashboard, archiveList, weeklyReport)` composite mapper computing KPI + leads + blocked/at-risk + archive
- All 5 admin tab components fetch from `trpc.admin.snapshot` (or `getSettings` for SettingsTab) — local `useState(MOCK_*)` initial state replaced with `useState(mapped)`, mutations preserved as no-ops with inline TODO(Phase-22) markers
- Dashboard page composes 3 queries with `useQuery` + skeleton + toast
- Skeletons matching final card / table dimensions to prevent layout shift
- Mapper unit tests
  </objective>
