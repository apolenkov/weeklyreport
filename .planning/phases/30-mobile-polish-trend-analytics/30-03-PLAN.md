<objective>
ANAL-04 surfaces the analytics data from 30-01/30-02 in a viewer-accessible RSC page. Three small chart components (sparkline, stacked bar, delta table) sit at the client boundary while the page itself stays server-rendered for fast TTFB and indexable HTML.

Key technical concerns:

1. Recharts requires the DOM (uses ResizeObserver, getBoundingClientRect) — chart components must be `'use client'` and lazy-imported via `next/dynamic` with `ssr: false`.
2. Null vs zero must look different. The CONTEXT D-3 pitfall warns that recharts default behavior connects across nulls — we set `connectNulls={false}` so gaps render visibly.
3. shadcn-ui Chart install is best-effort — if `pnpm dlx shadcn@latest add chart` exceeds the 60s time-box, hand-roll a 30-LOC wrapper around recharts that exports `ChartContainer` and `ChartTooltip` (the only primitives we need).

</objective>

    ```typescript
    import dynamic from 'next/dynamic';
    import { createServerCaller } from '../../../../lib/server/trpc-server';

    const TrafficLightHistoryChart = dynamic(
      () => import('../../../../components/charts/traffic-light-history.chart').then((m) => m.TrafficLightHistoryChart),
      { ssr: false },
    );
    const LeadVelocityChart = dynamic(
      () => import('../../../../components/charts/lead-velocity.chart').then((m) => m.LeadVelocityChart),
      { ssr: false },
    );
    const PeriodComparisonChart = dynamic(
      () => import('../../../../components/charts/period-comparison.chart').then((m) => m.PeriodComparisonChart),
      { ssr: false },
    );

    export default async function TrendsPage() {
      const caller = await createServerCaller();
      const periodFrom = '2026-01-01';
      const periodTo = '2026-12-31';
      const periodA = '2026-04-21';
      const periodB = '2026-04-28';
      const [history, velocity, comparison] = await Promise.all([
        caller.analytics.trafficLightHistory({ periodFrom, periodTo }),
        caller.analytics.leadVelocity({ periodFrom, periodTo }),
        caller.analytics.periodComparison({ periodA, periodB }),
      ]);

      return (
        <main className="mx-auto max-w-6xl space-y-8 px-4 py-8">
          <h1 className="text-2xl font-semibold">Trends</h1>
          <section><TrafficLightHistoryChart {...history} /></section>
          <section><LeadVelocityChart rows={velocity} /></section>
          <section><PeriodComparisonChart {...comparison} /></section>
        </main>
      );
    }
    ```
