<objective>
AUTH-06 hides nav links to routes the current role cannot reach. Today, `apps/web/src/components/navigation/app-shell.tsx` carries a hard-coded title table (`pageTitles`) plus a `getRoleLabel` helper, but the actual link list (in `nav-bar.tsx` or rendered by the shell) is rendered identically for every role — viewers see admin-shaped links that 403 on click. This plan filters the link list by role.

Per CC-1 (PITFALLS.md and CONTEXT.md sequencing): this plan ships LAST in Phase 29 because navigation hide is cosmetic. If it shipped before 29-03 (SSR layout gate) or 29-04 (SAML cut-over), the user experience would be: link is hidden in the nav, but a stale tab / external bookmark still loads the page → confusion. The depends_on=[29-01..29-05] in this plan's frontmatter is the machine-readable enforcement of CC-1.

This is the smallest plan in Phase 29: one new helper module, one filter call in two existing files, one test matrix. There is no schema change, no new tRPC procedure, no new env var, no new BullMQ work.

    ```typescript
    import type { Role } from '@customreport/shared';

    type RoutePrefix = '/admin' | '/head' | '/lead' | '/reports';

    export const ROUTE_ROLE_MAP: Readonly<Record<RoutePrefix, ReadonlyArray<Role>>> = {
      '/admin': ['admin', 'head'],
      '/head': ['head', 'admin'],
      '/lead': ['lead', 'head', 'admin'],
      '/reports': ['lead', 'head', 'admin', 'viewer'],
    };

    export function isRouteVisible(route: string, role: Role): boolean {
      for (const [prefix, allowed] of Object.entries(ROUTE_ROLE_MAP) as Array<[RoutePrefix, ReadonlyArray<Role>]>) {
        if (route === prefix || route.startsWith(prefix + '/')) {
          return allowed.includes(role);
        }
      }
      // Routes not in the map (e.g. '/auth/login') are always visible to authenticated users.
      return true;
    }
    ```

    Step 1.2 — Create `apps/web/src/lib/role-visibility.test.ts` covering the matrix:

    ```typescript
    import { describe, it, expect } from 'vitest';
    import { isRouteVisible } from './role-visibility';
    import type { Role } from '@customreport/shared';

    type Case = { route: string; role: Role; expected: boolean };
    const cases: ReadonlyArray<Case> = [
      // viewer
      { route: '/admin', role: 'viewer', expected: false },
      { route: '/head/dashboard', role: 'viewer', expected: false },
      { route: '/lead/report', role: 'viewer', expected: false },
      { route: '/reports/history', role: 'viewer', expected: true },
      // lead
      { route: '/admin', role: 'lead', expected: false },
      { route: '/head/dashboard', role: 'lead', expected: false },
      { route: '/lead/report', role: 'lead', expected: true },
      { route: '/reports/history', role: 'lead', expected: true },
      // head
      { route: '/admin', role: 'head', expected: true },
      { route: '/head/dashboard', role: 'head', expected: true },
      { route: '/lead/report', role: 'head', expected: true },
      // admin
      { route: '/admin', role: 'admin', expected: true },
      { route: '/head/dashboard', role: 'admin', expected: true },
    ];

    describe('isRouteVisible', () => {
      for (const c of cases) {
        it(`role=${c.role} sees ${c.route} → ${c.expected}`, () => {
          expect(isRouteVisible(c.route, c.role)).toBe(c.expected);
        });
      }

      it('unmapped routes are visible to all authenticated roles', () => {
        expect(isRouteVisible('/something-else', 'viewer')).toBe(true);
      });
    });
    ```

    ```typescript
    import type { Role } from '@customreport/shared';

    type NavItem = { href: string; label: string };
    const NAV_ITEMS: ReadonlyArray<NavItem> = [
      { href: '/lead/report', label: 'My report' },
      { href: '/lead/history', label: 'My history' },
      { href: '/head/dashboard', label: 'Dashboard' },
      { href: '/head/report', label: 'Assembled report' },
      { href: '/reports/history', label: 'Published history' },
      { href: '/admin', label: 'Admin' },
    ];

    export function NavBar({ role }: { readonly role: Role }) {
      const visible = NAV_ITEMS.filter((item) => isRouteVisible(item.href, role));
      return (
        <nav>
          {visible.map((item) => (
            <Link key={item.href} href={item.href}>{item.label}</Link>
          ))}
        </nav>
      );
    }
    ```
