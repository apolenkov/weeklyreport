# Phase 44-02 — Shared zod schema + tRPC contract

**Status:** ready
**Depends on:** 44-01 (Prisma model must exist before zod schema can mirror it)
**Requirement:** UFB-036 (Reminder Policy model)

## Goal

Expose `ReminderPolicy` to the frontend via a typed tRPC surface:
`admin.listPolicies`, `admin.savePolicy`, `admin.removePolicy`. Add the
matching zod schema to `packages/shared`. Drop the `admin.saveReminderRule`
write path (read remains for the derived-rules visualization in 44-04).

## Acceptance Criteria

- `packages/shared/src/admin/reminder-policy.schema.ts` exports `reminderPolicySchema` + `ReminderPolicy` type
- `apps/api/src/modules/admin/admin.service.ts` has `savePolicy(input)`, `removePolicy({id})`, `listPolicies()` methods
- `apps/api/src/modules/admin/admin.prisma-repository.ts` has matching repo methods
- tRPC router exposes `admin.listPolicies`, `admin.savePolicy`, `admin.removePolicy` (all under `headProcedure`)
- `admin.saveReminderRule` write path returns `TRPCError({ code: 'METHOD_NOT_SUPPORTED' })` with message pointing to `admin.savePolicy`
- AdminSnapshot zod schema gains `policies: ReminderPolicy[]` field
- All existing api tests pass; `admin.contract.test.ts` covers the new endpoints

## Steps

1. Create `packages/shared/src/admin/reminder-policy.schema.ts`:
   ```ts
   import { z } from "zod";
   export const reminderPolicySchema = z.object({
     id: z.string().uuid(),
     kind: z.enum(["deadline", "escalation", "follow_up"]),
     offsetMinutes: z.number().int(),
     timezone: z.string().min(1),
     audience: z.enum(["lead-with-draft", "head-of-late"]),
     active: z.boolean(),
   });
   export type ReminderPolicy = z.infer<typeof reminderPolicySchema>;
   ```
2. Wire export in `packages/shared/src/index.ts`
3. Extend `adminSnapshotSchema` to include `policies: z.array(reminderPolicySchema)`
4. Add repo methods in `admin.prisma-repository.ts`:
   - `listReminderPolicies(): Promise<ReminderPolicy[]>`
   - `saveReminderPolicy(policy: ReminderPolicy): Promise<ReminderPolicy>` (upsert by id)
   - `archiveReminderPolicy(policyId: string): Promise<void>` (soft via active=false; hard delete only when no derived rules exist — guard explicit)
5. Add service methods in `admin.service.ts` mirroring repo + zod parse on input
6. Wire tRPC router (`apps/api/src/infrastructure/trpc/trpc.router.ts`):
   ```ts
   admin: router({
     listPolicies: headProcedure.query(({ ctx }) =>
       ctx.adminService.listPolicies(),
     ),
     savePolicy: headProcedure
       .input(reminderPolicySchema)
       .mutation(({ ctx, input }) => ctx.adminService.savePolicy(input)),
     removePolicy: headProcedure
       .input(z.object({ id: z.string().uuid() }))
       .mutation(({ ctx, input }) => ctx.adminService.removePolicy(input.id)),
     // existing endpoints unchanged…
   });
   ```
7. Replace body of `saveReminderRule` mutation with throwing handler:
   ```ts
   throw new TRPCError({
     code: "METHOD_NOT_SUPPORTED",
     message:
       "Per-period reminder rules are read-only as of Phase 44. Use admin.savePolicy instead.",
   });
   ```
8. Add audit log calls in `savePolicy` / `removePolicy` (uses `auditLogger.policySave({...})` — implement helper in 44-05)
