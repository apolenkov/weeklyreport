**1. Create `apps/api/src/modules/auth/auth.routes.ts`** with a `mountAuthRoutes` function that takes the Express app, Passport SAML strategy, auth controller, and PrismaClient:

```typescript
export function mountAuthRoutes(
  expressApp: Express,
  samlStrategy: SamlStrategy,
  authController: ReturnType<typeof createAuthController>,
  prisma: PrismaClient,
  env: NodeJS.ProcessEnv,
): void
```

Three routes:
- `GET /auth/saml/login` — calls `passport.authenticate('saml')` which redirects to Keycloak. Must call `passport.initialize()` middleware first. Pass `{ session: false }` to avoid Passport session serialization (per Pitfall 6).
- `POST /auth/saml/callback` — CRITICAL: mount `express.urlencoded({ extended: false })` BEFORE `passport.authenticate('saml', { session: false })` (per Pitfall 2). After successful auth, `req.user` contains `{ samlId, email, displayName, role }`. Upsert user in DB via `prisma.user.upsert({ where: { samlId: req.user.samlId }, update: { email, name }, create: { samlId, email, name, role } })`. Include `authoredReportSections` to find active report/section. Build `UserSession` from DB user. Call `authController.issueSessionCookie(session)`. Set cookie header: `res.setHeader('Set-Cookie', setCookieHeader)`. Redirect to `env.FRONTEND_URL ?? 'http://localhost:3000'`. On error, redirect to `${env.FRONTEND_URL}/auth/error?reason=invalid_assertion`.
- `POST /auth/logout` — clear cookie by setting `customreport_session` with `maxAge: 0` and redirect to `/`.

Also add a `GET /auth/dev-login` route (only when `AUTH_DEV_MODE=true`) that creates a dev session cookie for the DEV_SESSION user and redirects to frontend. This enables frontend dev mode to get a real cookie without Keycloak.

Initialize passport at module level: `passport.use('saml', samlStrategy)`.

**2. Update `apps/api/src/infrastructure/trpc/trpc.context.ts`** — replace the `// Phase 6` placeholder comment with actual JWT extraction:

```typescript
import { createAuthController } from '../../modules/auth/auth.controller.js';

export function createContextFactory(_app: INestApplication) {
  const authController = createAuthController(process.env);

  return async ({ req }: CreateExpressContextOptions): Promise<TrpcContext> => {
    if (process.env['AUTH_DEV_MODE'] === 'true') {
      return { session: DEV_SESSION };
    }

    const token = req.cookies?.['customreport_session'];
    if (!token) {
      return { session: null };
    }

    try {
      const session = authController.verifySessionToken(token);
      return { session };
    } catch {
      return { session: null };
    }
  };
}
```

A client component (`'use client'`) that reads `reason` from the URL search params via `useSearchParams()`.

Error reason mapping:
- `idp_unavailable` -> heading: `Authentication Error`, body: `The authentication service is currently unavailable. Please try again in a few minutes.`

- (missing or unknown) -> heading: `Authentication Error`, body: `Something went wrong during sign-in. Please try again.`
