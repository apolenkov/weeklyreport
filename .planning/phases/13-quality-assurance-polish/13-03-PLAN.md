    **BUG-018 (P1): Add timeZone: 'UTC' to period date formatters.**
    For ALL date formatting calls that display report period dates (periodStart, periodEnd), add `{ timeZone: 'UTC' }` to the options.
    Period dates are stored as midnight UTC — without the timeZone option, users in UTC+3 see the previous day.
    If you created the utility above, `formatPeriodDate` already handles this.

    **BUG-019 (P1): Make DataTable sort headers keyboard-accessible.**
    In data-table.tsx (packages/ui/src/components/data-table.tsx), find the `<th>` elements that have `onClick` for sorting.
    Add keyboard support:
    ```tsx
    <th
      tabIndex={column.sortable ? 0 : undefined}
      role={column.sortable ? 'button' : undefined}
      aria-sort={/* current sort direction */}
      onClick={() => handleSort(column.id)}
      onKeyDown={(e) => {
        if (e.key === 'Enter' || e.key === ' ') {
          e.preventDefault();
          handleSort(column.id);
        }
      }}
      className="cursor-pointer select-none"
    >
    ```
    Also add `aria-sort="ascending"`, `aria-sort="descending"`, or `aria-sort="none"` based on current sort state.
