    In globals.css, find the CSS custom properties for the skeleton component (likely `--skeleton` or used via Tailwind's `bg-muted` or `bg-accent`).
    The problem: skeleton loading states use accent color that is nearly invisible against the background.
    Fix by ensuring skeleton has at least 3:1 contrast ratio:
    - If skeleton uses `--accent`, create a dedicated `--skeleton` token: `--skeleton: oklch(0.88 0.01 250);` (light gray, visible on both light and dark backgrounds)

    - Add a `.skeleton` class override if needed:
    ```css
    .skeleton {
      background: var(--skeleton, oklch(0.88 0.01 250));
    }
    ```

    Look for:

    - Hardcoded `destructive` or `bg-destructive` classes
    - Hardcoded hex/oklch color values

    - For "resolved" status: use `text-success` / `bg-success/10` (or create a `--success` token if it does not exist in globals.css)
