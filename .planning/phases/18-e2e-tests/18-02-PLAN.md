# Phase 18 Plan 02 — Head Journey E2E

## Objective

Implement Head role E2E tests: dashboard, weekly report, publish & lock, PDF
export (E2E-02).

## Requirements Closed

- **E2E-02**: Head journey: login → dashboard KPIs → weekly report → publish & lock → PDF

## Step 1 — Dashboard E2E

### Test file: `apps/web/e2e/head-dashboard.spec.ts`

### Scenarios (~10 tests)

1. Head logs in → redirected to /head/dashboard
2. KPI cards show submissions count (e.g., 4/6)
3. KPI cards show deadline countdown
4. KPI cards show escalation count
5. Alert bar visible when leads haven't submitted
6. Lead Reports grid shows 6 lead cards
7. Each lead card shows status badge and traffic light dots
8. Submitted lead card has "Revoke" button
9. Report Archive section shows past published reports
10. Toggle All button collapses/expands sections

Covers: SC-20..SC-25 (Dashboard), SC-59 (responsive)

## Step 2 — Weekly Report E2E

### Test file: `apps/web/e2e/weekly-report.spec.ts`

### Scenarios (~10 tests)

1. Head navigates to /head/report
2. Period navigator shows current week
3. Period navigator arrows switch periods
4. Portfolio overview table shows products with worst-case status
5. Per-lead accordions expand with full data
6. Current/Next Week items visible in accordion
7. Risks and Decisions visible in accordion
8. "Live · 4/6 Submitted" badge shows correct count
9. Publish & Lock button triggers confirmation dialog
10. After publish: period locks, "Published" badge visible

Covers: SC-26..SC-30 (Weekly Report)

## Step 3 — PDF Export E2E

### Test file: `apps/web/e2e/pdf-export.spec.ts`

### Scenarios (~3 tests)

1. Export PDF button triggers async job
2. Progress indicator appears during export
3. Download link available after completion (or mock check)

## Exit Criteria

1. All 10 dashboard tests pass
2. All 10 weekly report tests pass
3. PDF export flow tested (3 tests)
4. `pnpm playwright test` exits 0

## Estimated Scope

- ~3 test files
- ~600 lines of test code
- ~23 test cases
