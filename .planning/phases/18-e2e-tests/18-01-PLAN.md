# Phase 18 Plan 01 — Auth Fixtures + Lead Journey E2E

## Objective

Set up Playwright E2E test infrastructure (auth fixtures, helpers, seeded data)
and implement the Lead journey E2E tests (E2E-01).

## Requirements Closed

- **E2E-01**: Lead journey: login stub → select period → fill all sections → submit → locked

## Step 1 — Test Infrastructure

### Files to create

- `apps/web/e2e/auth.setup.ts` — Playwright global setup: login via stub, save auth state
- `apps/web/e2e/fixtures.ts` — custom test fixtures with auth context per role
- `apps/web/e2e/helpers/test-utils.ts` — reusable helpers (login, navigate, wait for API)
- `apps/web/playwright.config.ts` — update config with projects (lead, head, admin, viewer)

### Auth pattern

```typescript
// fixtures.ts
export const leadTest = test.extend({
  page: async ({ browser }, use) => {
    const context = await browser.newContext({
      storageState: "lead-auth.json",
    });
    const page = await context.newPage();
    await use(page);
    await context.close();
  },
});
```

Each role logs in via `/auth/dev-login?role=<role>` in global setup and saves
the cookie state to a JSON file.
