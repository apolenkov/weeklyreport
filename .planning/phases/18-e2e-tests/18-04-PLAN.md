# Phase 18 Plan 04 — Cross-Role Lifecycle + Revoke E2E

## Objective

Test multi-role workflows: lead submits → head publishes → lead sees locked →
head reopens (E2E-04) and revoke flow (E2E-05).

## Requirements Closed

- **E2E-04**: Cross-role lifecycle
- **E2E-05**: Revoke flow

## Test file: `apps/web/e2e/cross-role-lifecycle.spec.ts`

### Cross-Role Lifecycle (E2E-04) (~6 tests)

1. Lead submits report section → status changes to "Submitted"
2. Head sees submitted status on dashboard lead card
3. Head publishes period via Weekly Report → "Publish & Lock" flow
4. Lead navigates to form → sees "Published" read-only state
5. Head reopens period → lead form becomes editable again
6. Lead re-edits and re-submits after reopen

### Revoke Flow (E2E-05) (~4 tests)

7. Head clicks "Revoke" on submitted lead card → confirmation dialog
8. Head confirms revoke → lead card status changes to "Draft"
9. Lead navigates to form → form is editable again (draft state)
10. Lead re-fills and re-submits after revoke

Covers: SC-39..SC-46 (Access Control partial), cross-role scenarios

## Test Setup

Each test uses multiple browser contexts (one per role) to simulate
multi-user workflows:

```typescript
test("cross-role lifecycle", async ({ browser }) => {
  const leadPage = await loginAs(browser, "lead");
  const headPage = await loginAs(browser, "head");
  // Lead submits...
  // Head publishes...
  // Lead verifies locked...
});
```

## Exit Criteria

1. Full lifecycle test passes end-to-end
2. Revoke flow test passes
3. Multi-browser-context setup works reliably

## Estimated Scope

- 1 test file
- ~300 lines of test code
- ~10 test cases
