# Phase 18 Plan 05 — Period Nav + Fill From + Version History E2E

## Objective

Test period navigation, fill-from-previous, and autosave version history
features (E2E-06, E2E-07, E2E-08).

## Requirements Closed

- **E2E-06**: Period navigation: lead switches periods → past read-only → current editable
- **E2E-07**: Fill from: lead fills from past period → warning → data populated
- **E2E-08**: Version history: autosave creates versions → rollback

## Test file: `apps/web/e2e/period-features.spec.ts`

### Period Navigation (E2E-06) (~5 tests)

1. Lead sees current period selected in navigator
2. Click left arrow → navigates to previous period
3. Previous period form is read-only (inputs disabled)
4. Click right arrow → back to current period (editable)
5. Period combobox dropdown lists all available periods

### Fill From (E2E-07) (~4 tests)

6. "Fill from Previous" button visible on current period
7. Click → confirmation dialog "This will overwrite your draft"
8. Confirm → form populated with data from selected past period
9. Cancel → form unchanged

### Version History (E2E-08) (~5 tests)

10. After typing, autosave indicator shows "Autosaved"
11. Version navigator shows current version number
12. Click left arrow → shows previous version
13. "Restore" button restores to selected version
14. After restore → form data matches restored version

Covers: SC-100..SC-130 (advanced scenarios for D-64, D-65, D-67)

## Exit Criteria

1. Period navigation switches correctly between periods
2. Past periods render as read-only
3. Fill From copies data with confirmation
4. Version history navigates and restores correctly
5. All 14 tests pass

## Estimated Scope

- 1 test file
- ~350 lines of test code
- ~14 test cases
