# Phase 19 Plan 03 — Developer Onboarding + User Guide

## Objective

Create developer onboarding docs (local setup, dev workflow) and a user guide
with role-based workflows.

## Deliverables

1. `docs/DEVELOPER.md` — developer onboarding
2. `docs/USER-GUIDE.md` — end-user guide with screenshots

## Part 1: Developer Onboarding (docs/DEVELOPER.md)

### Sections

1. **Quick Start** — clone, install, docker up, seed, dev servers
2. **Monorepo Structure** — apps/api, apps/web, packages/shared, packages/ui
3. **Development Workflow** — turborepo tasks, hot reload, typecheck
4. **Database** — Prisma schema, migrations, seed, studio
5. **Testing** — vitest (unit/contract), playwright (E2E), running specific tests
6. **Adding a New Feature** — where to add schemas, services, routes, components
7. **Code Quality** — ESLint, Prettier, Husky pre-commit hooks
8. **Troubleshooting** — common issues (port conflicts, Prisma drift, auth errors)

## Part 2: User Guide (docs/USER-GUIDE.md)

### Sections by Role

#### Lead

1. Logging in (SSO or dev stub)
2. Filling out the weekly report form
3. Understanding SDLC pipeline and stage ownership
4. Submitting the report
5. Viewing history and past submissions
6. Using Fill From Previous
7. Version history and rollback

#### Head

1. Dashboard overview (KPIs, alerts, lead status)
2. Reviewing the Weekly Report
3. Publishing & Locking a period
4. Reopening a period
5. Revoking a lead's submission
6. Exporting to PDF
7. Browsing report archive

#### Admin

1. Managing users (add, edit roles, remove)
2. Managing products and stage assignments
3. Managing report periods
4. Configuring reminders
5. Updating department settings

### Screenshots

Reference mockup screenshots from `mockups/screenshots/` for each section:

- s1 → Lead Form workflows
- s2 → Dashboard workflows
- s3 → Weekly Report workflows
- s4 → Admin Panel workflows
- s8 → Login flow

## Exit Criteria

1. `docs/DEVELOPER.md` enables new developer setup in < 30 minutes
2. `docs/USER-GUIDE.md` covers all role workflows with screenshot references
3. No broken links or missing references

- 2 files (~500 lines total)
