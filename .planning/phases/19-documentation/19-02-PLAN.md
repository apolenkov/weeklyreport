# Phase 19 Plan 02 — Deployment Guide

## Objective

Document production deployment: Docker Compose setup, environment variables,
health checks, monitoring, backup procedures.

## Deliverable

`docs/DEPLOYMENT.md`

## Sections

### 1. Prerequisites
- Docker 27+, Docker Compose 2.x
- PostgreSQL 15+ (or via container)
- Redis 7+ (or via container)
- Keycloak instance for SSO (optional — login stub available)

### 2. Environment Variables

Document every env var from `apps/api/src/infrastructure/config/env.schema.ts`:
- `DATABASE_URL` — PostgreSQL connection string
- `REDIS_URL` — Redis connection
- `AUTH_JWT_SECRET` — JWT signing secret
- `FRONTEND_URL` — Next.js app URL
- `SAML_*` — Keycloak SAML config
- `SMTP_*` — Email server config
- `AUTH_DEV_MODE` / `NEXT_PUBLIC_AUTH_STUB` — dev mode flags

### 3. Docker Compose Production

- `docker-compose.prod.yml` usage
- Volume mounts for PostgreSQL data
- Network isolation
- Container resource limits

### 4. Database Management

- Initial migration: `prisma migrate deploy`
- Seed data: `prisma db seed`
- Backup: `pg_dump` script
- Rollback procedure

### 5. Health Checks & Monitoring

- `/health/live` — liveness probe
- `/health/ready` — readiness probe (DB + Redis + queues)
- `/metrics` — Prometheus metrics
- BullMQ Bull Board UI

### 6. SSL/TLS & Reverse Proxy

- nginx/Caddy configuration example
- CORS setup
- Cookie security settings

## Exit Criteria

1. `docs/DEPLOYMENT.md` covers full production setup
2. Fresh deploy possible following the guide
3. All env vars documented with defaults

## Estimated Scope

- 1 file (~400 lines)
