<objective>
Ship the `requireRole` tRPC middleware factory plus its default-deny coverage test. This is the keystone of v6.0 role enforcement — Phase 28 (AUTH-04) consumes the factory; Phase 29 (AUTH-06/07) consumes its types via the shared package; the coverage test is the CI gate that prevents silent bypass.

Per CONTEXT.md D-AUTH-03:

- Factory lives in `packages/shared/src/trpc/middleware/role.ts` (NOT `apps/api`) so contracts and types are co-located with the schema layer.
- Four named procedures emitted: `leadProcedure`, `headProcedure`, `adminProcedure` (= `headProcedure` for v6.0), `viewerProcedure`.
- The existing api `headProcedure` is REFACTORED (implementation only) — its export name and contract are preserved; the `trpc.router.ts` consumers are NOT migrated in this phase (that is Phase 28's AUTH-04).
- Default-deny coverage test fails CI if any procedure on the AppRouter lacks role declaration.

Subtle issue: the factory needs the caller's `t` instance (the api's `initTRPC.context<TrpcContext>().create(...)` produces a typed t that carries TrpcContext; the shared package cannot own that context type because TrpcContext lives in api). Therefore `requireRole` must be a **factory of factories** — accept `t` as its first argument (or be parameterised by a tRPC builder type) and return the role-bound middleware/procedure.

Purpose: lock the v6.0 role-enforcement contract; immunise the codebase against silent role bypass.
Output: shared middleware module + subpath export + api refactor + coverage CI gate + unit tests.

Factory signature target (in packages/shared/src/trpc/middleware/role.ts):

```typescript
import type {
  TRPCBuilder,
  AnyRootTypes,
} from "@trpc/server/unstable-core-do-not-import";
import { TRPCError } from "@trpc/server";
import type { Role, UserSession } from "../../schemas/auth";

// Caller passes in their typed `t` instance (api's initTRPC...create()).
// We require ctx to have `session: UserSession | null`.
export function requireRole<
  TBuilder extends { middleware: any; procedure: any },
>(t: TBuilder, allowed: Role | Role[]) {
  const allowedSet = new Set(Array.isArray(allowed) ? allowed : [allowed]);
  const middleware = t.middleware(
    ({ ctx, next }: { ctx: { session: UserSession | null }; next: any }) => {
      if (!ctx.session) {
        throw new TRPCError({
          code: "UNAUTHORIZED",
          message: "Not authenticated",
        });
      }
      if (!allowedSet.has(ctx.session.role)) {
        throw new TRPCError({
          code: "FORBIDDEN",
          message: `Role required: ${[...allowedSet].join(" | ")}`,
        });
      }
      return next({ ctx: { session: ctx.session } });
    },
  );
  return { middleware };
}
```
