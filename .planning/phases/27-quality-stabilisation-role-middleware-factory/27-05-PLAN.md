      The fix is a tighter `waitForResponse` helper. Add (or update) `apps/web/e2e/integration/helpers/waitForTrpc.ts` exporting a function:
      ```typescript
      export async function waitForTrpcMutation(
        page: Page,
        procedureName: string, // e.g. 'reportSection.saveDraft'
        opts?: { method?: 'POST' | 'GET'; timeout?: number; predicate?: (body: unknown) => boolean },
      ): Promise<Response> {
        return page.waitForResponse(
          (response) => {
            if (response.request().method() !== (opts?.method ?? 'POST')) return false;
            const url = response.url();
            // Match a procedure name as a path component or in tRPC v11 batch URL.
            // Batch URL pattern: /trpc/proc1,proc2,proc3
            // Single URL pattern: /trpc/proc1
            const match = new RegExp(`/trpc/(?:[^,?]+,)*${escapeRegExp(procedureName)}(?:,|\\?|$)`);
            if (!match.test(url)) return false;
            if (opts?.predicate) {
              // tRPC body is JSON; parse and apply predicate to disambiguate
              // when the same procedure fires multiple times in the test.
              try {
                const body = response.request().postDataJSON();
                if (!opts.predicate(body)) return false;
              } catch {
                return false;
              }
            }
            return true;
          },
          { timeout: opts?.timeout ?? 15_000 },
        );
      }
      ```
      Then update each of the 5 failing test sites to use `waitForTrpcMutation(page, '<procedure>', { predicate: (b) => /* disambiguate from autosave */ })` instead of bare `page.waitForResponse(r => r.url().includes('/trpc/'))`.
      The `predicate` is the disambiguator — for example, the autosave mutation fires with `status: 'draft'` while the explicit "publish" click fires with `status: 'published'`. The predicate filters on the body to await the RIGHT call.
