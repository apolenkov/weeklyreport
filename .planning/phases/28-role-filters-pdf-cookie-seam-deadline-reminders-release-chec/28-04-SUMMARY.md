## tools/handoff-sync.ts

- 3 exported pure functions: `parseUntickedItems`, `buildSection`, `rewriteHandoff`. The `main()` orchestrator reads CHECKLIST.md and HANDOFF.md, computes the new section, writes back only when changed.
- Marker pair: `<!-- handoff-sync:start -->` / `<!-- handoff-sync:end -->`. Idempotent: rerunning the tool after a no-op edit produces the literal log line `handoff-sync: HANDOFF.md already up to date (20 items)`.
- Regex: `/^- \[ \] ([A-Z]+-[A-Z]+-\d{3}) \[(manual|CI)\] [——-] (.+)$/gm` — accepts em-dash (U+2014), en-dash, or hyphen separator; tolerates the unicode em-dash actually present in CHECKLIST.md.
- 8 unit tests in `tools/handoff-sync.test.ts` cover the parse → buildSection → rewrite pipeline (idempotency, content preservation, append branch, zero-count branches).
