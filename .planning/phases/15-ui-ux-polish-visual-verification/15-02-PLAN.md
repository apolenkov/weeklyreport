   - Group visible items by `group` property using a reduce or Map
   - For each group, render a `<SidebarGroup>` with `<SidebarGroupLabel>` and the items inside `<SidebarMenu>`
   - If a role has only 1 group (e.g., lead with just "Reports"), still use the group label for consistency
   - SidebarGroupLabel automatically hides in collapsed (icon-only) mode via the shadcn/ui sidebar component

Pattern for grouped rendering:

```typescript
const groups = Object.entries(
  Object.groupBy(visibleItems, (item) => item.group)
);

return (
  <>
    {groups.map(([groupName, items]) => (
      <SidebarGroup key={groupName}>
        <SidebarGroupLabel>{groupName}</SidebarGroupLabel>
        <SidebarGroupContent>
          <SidebarMenu>
            {items.map((item) => {
              const Icon = item.icon;
              const isActive = currentPath === item.href;
              return (
                <SidebarMenuItem key={item.href}>
                  <SidebarMenuButton asChild isActive={isActive} tooltip={item.label}>
                    <Link href={item.href}>
                      <Icon className="h-5 w-5 shrink-0" />
                      <span>{item.label}</span>
                    </Link>
                  </SidebarMenuButton>
                </SidebarMenuItem>
              );
            })}
          </SidebarMenu>
        </SidebarGroupContent>
      </SidebarGroup>
    ))}
  </>
);
```

NOTE: Check if `Object.groupBy` is available in the TypeScript target (ES2024+). If not, use a manual reduce:

```typescript
const grouped = visibleItems.reduce<Record<string, typeof visibleItems>>(

    group.push(item);
    acc[item.group] = group;
    return acc;
  },
  {},
);
```
