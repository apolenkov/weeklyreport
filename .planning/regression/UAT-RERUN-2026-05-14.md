## One-Run Protocol

```bash
RUN_ID=uat-rerun-$(date +%Y%m%d-%H%M%S)
EVIDENCE=.planning/regression/evidence/$RUN_ID
mkdir -p "$EVIDENCE"

docker compose up -d --build postgres redis mailhog api web
docker compose ps | tee "$EVIDENCE/docker-ps.txt"

curl -fsS http://localhost:3000/ > /dev/null
curl -fsS http://localhost:3002/health/live | tee "$EVIDENCE/api-health.txt"

docker compose logs --no-color --timestamps postgres redis mailhog api web \
  > "$EVIDENCE/docker-startup.log"

cd apps/web
pnpm exec playwright test \
  --config e2e/regression/playwright.regression.config.ts \
  --reporter=list 2>&1 | tee "../../$EVIDENCE/playwright-regression.log"
cd ../..

cp .planning/regression/agent-b-test-results/results.json \
  "$EVIDENCE/results.json" 2>/dev/null || true
docker compose logs --no-color --timestamps postgres redis mailhog api web \
  > "$EVIDENCE/docker-after-regression.log"
```
