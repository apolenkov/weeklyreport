### Missing Connections

### Broken Flows

None at code-wire level. **Four flows lack runtime verification** (see E2E Flow Status table above).

### Unprotected Routes

`auth.me` uses `publicProcedure` deliberately (D-24-01-A) so the SessionProvider's first query does not throw on unauthenticated browsers and trigger a redirect loop. This is correct by design and is not an unprotected sensitive route — the procedure simply returns `null` when there is no session. All other tRPC procedures use `protectedProcedure` or `headProcedure` per existing v4.0 design.
