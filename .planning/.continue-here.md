## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `programmatic dispatchEvent('click')` for Radix popovers | A pure `el.dispatchEvent(new MouseEvent('click'))` does NOT activate Radix `onSelect` handlers (DropdownMenuItem, Dialog, etc.). Spent multiple turns "verifying" widget that needed a real-user click flow. | blocking | Use `mcp__plugin_playwright_playwright__browser_click` with the snapshot-derived ref, OR direct fetch-style verification (`page.evaluate(async () => fetch(/trpc/...))`) for tRPC mutations. NEVER conclude a Radix-mounted button is broken from a `dispatchEvent` test alone. |
| Empty-row filter in `sectionToDraftPayload` masking real bugs | Initial fix dropped empty rows from autosave to dodge `safeText({min:1})`. Worked for autosave, but hid that handlers were writing `risk: r.text` (a concat string) back into raw and double-concatenating every render. | advisory | When user reports "edit doesn't persist", trace the FULL round-trip raw → mapper → presentation → handler → raw, not just the autosave hop. |
| "TBD" placeholders for required schema fields | Earlier `lead-form.tsx` seeded `tag: 'general'`, `mitigation: 'TBD'`, `owner: 'TBD'` so autosave validation passed. Quietly violated the user's "I want all fields editable" mental model. | advisory | Modal-edit dialogs are now the source of truth for schema-required fields. Don't add new placeholder defaults — extend the dialog instead. |
| Owner-string mismatch | Decision Owner is free text. Earlier seed used `'Polenkov'` for owner but `'Polenkov A.'` for user.name → mine/owner-other comparison failed. Fixed by aligning seed labels to user.name (`'Aleksandr P.'`). | advisory | Any free-text identity comparison needs a normalize layer (current `isMine` does case-loose + trailing-punctuation strip) AND consistent seed values. |
