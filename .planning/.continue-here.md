## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---------|-------------|----------|------------|
| Playwright actionability vs fixed-position portal | Stage popover (apps/web/src/components/lead/stage-chip.tsx) renders via portal with fixed positioning. Playwright's hit-test rejects clicks even with `force: true`, `scrollIntoViewIfNeeded`, `focus()+keyboard.press('Enter')`, `dispatchEvent('click')`, AND `evaluate(el.click())` (the last works in MCP debug but not the Playwright runner). | blocking | For the test suite, skip with TODO. Long-term fix: have dialog onSave return the mutation Promise so the helper can `await mutation` instead of fishing for the response in the network log. |
| Empty-row filter in repo dropping ProjectStatus rows | `report-sections.prisma-repository.ts saveSection` used to `.filter((p) => p.trafficLight !== null)` before recreating rows in the deleteMany+createMany cycle, so picking Clear erased the lead's assignment and orphaned items+risks under "Unknown". | blocking (fixed `b549eca`) | Migration nullable-project-status + drop the filter. Resolved. |
| `pointer-events: none` on hover overlay defeats Playwright force-click | ItemCard action buttons sit inside a `pointer-events-none` wrapper that flips to `pointer-events-auto` only on `:hover`. Without `card.hover()` the inner button receives `force: true` clicks but the parent intercepts. | advisory | helpers/lead-form.ts now hovers the card before clicking pencil/trash. |
| Bare `Edit` / `Delete` accessible name matches every action button on the page | `getByRole('button', { name: 'Edit' })` resolved to 7 elements (`Edit risk for…`, `Edit decision`, etc.). | advisory | Use `{ name: 'Edit', exact: true }` AND scope by `data-testid="item-card"` (added in commit `e888090`). |
| Empty-row filter in `sectionToDraftPayload` masking real bugs | Earlier fix dropped empty rows from autosave to dodge `safeText({min:1})`. Hid that handlers were writing `risk: r.text` (a concat string) back into raw and double-concatenating every render. | advisory | When user reports "edit doesn't persist", trace the FULL round-trip raw → mapper → presentation → handler → raw. |
| autosave debounce + reload race in E2E | After a dialog Save closes the modal, the next saveDraft is debounced ~600ms. `waitForResponse` and `waitForLoadState('networkidle')` both raced this window; `waitForTimeout(2000)` was the cheapest reliable barrier but still flaked S2.2. | advisory | Long-term: dialog onSave returns mutation Promise. Short-term: test.skip with TODO. |
