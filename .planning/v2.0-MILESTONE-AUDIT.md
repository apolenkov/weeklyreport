## Critical Gaps

### 1. PDF Print Page Missing (JOBS-02)

`pdf-export.processor.ts` navigates to `/reports/${reportId}/print` but no such route exists.
Playwright generates PDF of a 404 page.

**Fix:** Create `apps/web/src/app/(app)/reports/[reportId]/print/page.tsx` — renders report without navigation.

### 2. Email Reminder Queue Not Connected (JOBS-03)

`RemindersService` creates a DB record with status `queued` but has no BullMQ queue injection.
`EmailReminderProcessor` exists but is never triggered.

**Fix:** Inject `Queue` into `RemindersService`, call `queue.add()` after `saveExecution()`.

### 3. Bull Board Unprotected (JOBS-04 partial)

`/admin/queues` is accessible without authentication. Requirement says head-role access.

**Fix:** Add JWT verification middleware before Bull Board router.
