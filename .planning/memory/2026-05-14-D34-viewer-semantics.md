# D34 — Viewer: что видит наблюдатель (Даша) в отличие от руководителя?

**Дата:** 2026-05-14  
**Источник:** UAT «а в чём тогда разница между head и viewer? viewer просто смотрит
отчёты и открывает презентацию, но и всё — дэшборд лишний, но статус кто заполнил
нужен, писать лично и редактировать нельзя»

## Текущее состояние (viewer)

- Может просматривать опубликованные отчёты (`/head/report/[id]`)
- Может экспортировать PDF
- Открыть презентацию
- Dashboard: видит те же карточки (`KpiCards`, `BlockedAtRiskTable`), что и head

## Проблема

Полный дашборд с `ActivityLivePanel`, `AlertBar` (напоминания), кнопкой
«View Status Report» — это инструменты управления, не просмотра.
Viewer не может ничего изменить, но видит интерфейс, рассчитанный на действия.
Это создаёт ложное ощущение «что-то можно сделать».

## Рекомендация

Заменить дашборд viewer-роли на отдельную страницу **«Status Board»**:

- Строки по лидам: имя, статус секции (сдал / не сдал / в работе), дата сдачи
- Счётчики периода: Submitted X/N, Deadline, Risks (только цифры, без кнопок)
- Ссылки: «Open Report» (на последний опубликованный), «Export PDF»
- Нет кнопки «Send Reminder», нет `AlertBar`, нет `ActivityLivePanel`

Полный head-дашборд остаётся только для ролей `head` и `admin`.

## Компромисс

```
Отдельная страница Status Board для viewer
  + Чётко разграничивает: viewer смотрит, head управляет
  + Меньше когнитивной нагрузки для Даши — не нужно игнорировать кнопки
  - Нужна новая страница + role-gate в роутере (~2–3 часа работы)

Скрыть кнопки действий через role-check в существующем дашборде
  + Быстрее (1 час)
  - Страница останется «дырявой»: layout рассчитан на head, пустые места
    после скрытия будут выглядеть как баги

Оставить как есть
  - Viewer путается: видит кнопки, которые не работают или не нужны
```

**Рекомендую:** отдельная страница `StatusBoardPage` для viewer.
Переход через role-aware redirect в `DashboardPage`.  
**Решение руководителя:** согласовать с D29 (метрики head) — часть данных
Status Board совпадает с `PeriodLeadSummaryTable`.
