# D16 — Priority Chips: первая буква + цвет стадии SDLC

**Дата:** 2026-05-14  
**Источник:** UAT «может сделать ограничения на стадии — цвета как при редактировании продуктов?»

## Текущее состояние

Компонент `PrioritiesSection` (`apps/web/src/components/lead/priorities-section.tsx`)
рендерит чипы стадий так:

- Фон: `var(--color-success)` (светло-зелёный) для всех стадий без исключения
- Цвет текста: `var(--color-primary)` (тёмно-зелёный)
- Текст: полное название стадии (например `Planning`, `Development`, `Testing`)

В `products-tab.tsx` стадии не имеют цветовой дифференциации — там отображается
только счётчик `N/7 stages`. Паттерна «первая буква + цвет стадии» в admin-таблице
продуктов не реализовано — это имелось в виду как желаемое.

## Предложение из UAT

Показывать на чипе первую букву стадии (`P`, `D`, `T`, `QA`, `Rel`…) вместо
полного названия, и окрашивать чип в цвет, соответствующий SDLC-позиции стадии
(например: зелёный → ранние стадии, жёлтый → тест, красный → пре-релиз).

## Рекомендация

Реализовать первую букву + цвет, но **взять схему цветов из существующей
семантики `Traffic` (red/yellow/green)**, а не из позиции стадии, которая
у всех продуктов разная. Это создаёт единую систему: тот же словарь цветов,
что используется в «светофоре» проектов.

Альтернатива — произвольная цветовая шкала по индексу стадии — может
вводить в заблуждение: индексная позиция не несёт семантики статуса.

## Компромисс

```
Первая буква + SDLC-позиция цветом
  + Компактно, визуально понятно
  - Порядок стадий у каждого продукта свой → цвет теряет смысл

Первая буква + фиксированная нейтральная палитра (по индексу)
  + Отличает стадии визуально без ложной семантики
  - Не отвечает на вопрос «что значит этот цвет»

Первая буква + нейтральный серый чип
  + Компактно, без путаницы
  - Теряет цветовую дифференциацию, которую просил пользователь
```

**Рекомендую:** первая буква + нейтральная палитра (5–6 фиксированных цветов
по порядковому номеру стадии в словаре SDLC), без привязки к Traffic-статусу.  
**Решение руководителя:** выбрать схему окраски или отказаться от цвета.
