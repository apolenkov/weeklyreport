## Overview

v8.0 shipped CustomReport into a deployable, observable, secured state. v8.1 closes the three gaps that were intentionally deferred at the v8.0 acceptance gate:

1. **Visual identity** — light theme reads "consumer" (Starbucks-inspired green). Internal stakeholders asked for a "more serious / B2B" look. Adds a dark mode baseline + a B2B palette refresh (less green saturation, more neutrals, professional typography). Self-driven PRD + design — no external designer.
2. **AI maturity** — Phase 31 shipped the AI summary card with partial eval coverage. v8.1 builds the eval harness (golden set + rubric runner), prompt regression suite, and observability metrics so AI features can ship safely.
3. **iOS Safari sign-off** — manual real-device verification, captured as a checklist + RUNBOOK addendum + screenshot evidence.

**Three themed phases:**

- **Phase 40 — B2B Rebrand & Dark Mode:** PRD (self-driven), design tokens (light B2B + dark), theme toggle UI + persistence, component audit pass, screenshot evidence.
- **Phase 41 — AI Eval & Monitoring:** golden-set seed (20-30 weekly reports + expected summaries), rubric runner (factual / relevant / concise / hallucination-free), prompt regression spec, `/metrics` AI counters + Grafana panels, daily cost alert.
- **Phase 42 — iOS Safari Sign-off:** RUNBOOK checklist addendum, manual sign-off harness, screenshot evidence on real device round.

## Key Themes

1. **Self-driven design** — no external dependency. v8.0 unblocked production; v8.1 polishes the front of house.
2. **AI safely shippable** — evaluation harness lets us bump prompts/models without regression panic.
3. **Mobile-real verification** — automated tests covered the desktop happy path; iOS round closes the loop.

## Phases

### Phase 40: B2B Rebrand & Dark Mode

**Goal:** Light B2B palette + dark theme baseline + theme toggle live, every component reads in both themes, screenshot evidence at 1280×800 + 375×667 + 768×1024.
**Depends on:** none
**Requirements:** BRAND-01..06
**Plans:** 5
**UI hint:** yes

Provisional plans:

- [ ] 40-01-PLAN — PRD: rebrand goals, palette, typography, motion. Self-authored. Two reference inspirations: Linear (sober dark) + Notion (light B2B). Output: `docs/REBRAND-PRD.md` + design tokens spec.
- [ ] 40-02-PLAN — Design tokens: `[data-theme="dark"]` block in `packages/ui/src/styles/globals.css` + light B2B refresh. Token migration: bump green saturation down 15%, raise contrast on text-on-success, add neutral-900 surface for dark mode.
- [ ] 40-03-PLAN — Theme toggle UI: nav-bar sun/moon button, `localStorage.theme` + `prefers-color-scheme` fallback, smooth transition.
- [ ] 40-04-PLAN — Component audit pass: every page, every dialog, every chart in both themes. Fix readability gaps (charts often die in dark mode). Charts: Recharts `<ResponsiveContainer>` colour palette pulled from CSS vars.
- [ ] 40-05-PLAN — Screenshot evidence + Storybook (or shadcn registry) snapshot: 5 routes × 2 themes × 3 viewports = 30 screenshots, committed to `docs/rebrand-evidence/`.

### Phase 41: AI Eval & Monitoring

**Goal:** Golden-set + rubric runner active in CI, prompt regression spec live, AI metrics in `/metrics` + Grafana panel, daily cost alert wired.
**Depends on:** none (parallel with 40)
**Requirements:** AI-EVAL-01..05
**Plans:** 5

Provisional plans:

- [ ] 41-01-PLAN — Golden-set seed: 20-30 weekly reports + expected summaries (hand-curated by domain expert — head of CoreDev). Stored in `apps/api/test-fixtures/ai-golden/*.json`.
- [ ] 41-02-PLAN — Rubric runner: vitest spec + LLM-as-judge (Haiku rates Haiku output) on four dimensions: factual / relevant / concise / hallucination-free. Pass threshold ≥4/5 average. Runs nightly in CI, not on every PR.
- [ ] 41-03-PLAN — Prompt regression spec: snapshot 5 known-good prompts + their outputs. Diff fails on prompt changes that don't bump version. Lives at `apps/api/src/modules/ai/ai.regression.test.ts`.
- [ ] 41-04-PLAN — `/metrics` counters: `cr_ai_tokens_total{kind=input|output}`, `cr_ai_latency_ms` histogram, `cr_ai_errors_total{failure_mode=...}`. Grafana panel JSON in `deploy/grafana-dashboard-ai.json`.
- [ ] 41-05-PLAN — Daily cost alert: BullMQ cron job sums tokens × Haiku price, alerts via existing log channel (`phase: 'ai.cost.alert'`) when daily cost > $5. Future iteration: email/Slack via SMTP.

### Phase 42: iOS Safari Sign-off

**Goal:** RUNBOOK addendum complete, manual sign-off round done on real iPhone + iPad, screenshot evidence committed.
**Depends on:** Phase 40 (test in final B2B theme, not the v8.0 green palette)
**Requirements:** MOB-01..03
**Plans:** 2

Provisional plans:

- [ ] 42-01-PLAN — RUNBOOK addendum + checklist: 25-item checklist covering PDF download (Safari download manager + Files app), tap-target audit at 375px, dialog scroll lock, sticky-header collisions, viewport zoom, share sheet, copy-link, period nav with browser back/forward.
