## Key Decisions

| Decision                                    | Outcome                                           |
| ------------------------------------------- | ------------------------------------------------- |
| Prisma 7 driver adapter pattern             | ✓ 3x faster queries, 90% smaller bundle           |
| tRPC auth as middleware (not NestJS guards) | ✓ Avoids guard bypass on tRPC routes              |
| superjson for Date serialization            | ✓ Resolved 17 type errors from JSON serialization |
| PgBouncer descoped                          | ✓ Unnecessary for 10 users/week                   |
| Big-bang localStorage replacement           | ✓ Cleaner than incremental migration              |
