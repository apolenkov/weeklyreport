## v8.0 Requirements

### Quality Foundation (Phase 34) — pre-commit + lint floor + audit gates

- [ ] **Q-01** — Husky + lint-staged installed and active. `git commit` runs prettier+eslint on staged files; commit-msg hook enforces Conventional Commits subject. Bypass via `--no-verify` allowed only with explicit warning in CONTRIBUTING. Pre-push hook runs `pnpm test` (skippable in `CI=true` env).
- [ ] **Q-02** — Vitest coverage thresholds enforced: web ≥ 70% statements / 60% branches; api ≥ 80% / 70%. CI step `pnpm test --coverage` fails under threshold. Coverage report uploaded as artifact.
- [ ] **Q-03** — DOM-walker + mutation-audit CI gate. `pnpm uat:audit` runs both tools, fails CI if any new BLACK HOLE mutation appears or if interaction inventory drops by ≥10% without a corresponding test/feature delta. Tools moved out of `.tmp/` into tracked `apps/web/uat-suite/`.
- [ ] **Q-04** — Prisma 7 migrate-reset CI gate. CI job spins ephemeral Postgres, runs `pnpm prisma migrate reset --force --skip-seed`, then `pnpm prisma generate`, asserts exit 0. Catches migration drift like the documented Prisma 7 quirk (was v7.0 API-03).
- [ ] **Q-05** — Pre-existing TypeScript error rollup: zero TS errors on `pnpm --filter @customreport/api typecheck` and `pnpm --filter @customreport/web typecheck`. One regression test per fix file. Mostly closed mid-2026-05-05 session; this requirement asserts clean-floor in CI (was v7.0 API-04).
- [ ] **Q-06** — ESLint warning floor: zero on `pnpm lint` for both apps. Test-file `no-non-null-assertion` warnings replaced with `expectDefined()` helper or proper narrowings. Service layer narrowings made explicit (was v7.0 API-01, ~272 warnings → 0).
- [ ] **Q-07** — Push-guard helper + E2E flaky-rate CI metric. `scripts/push-guard.sh` detects no-DNS state and prints `https_proxy=""` workaround. CI emits per-spec flaky rate (passed-on-retry / total) into a tracked metrics file (was v7.0 API-05+06).

### UX Polish (Phase 35) — visible regressions + v7.0 32-* + DLQ admin UI

- [ ] **UX-08** — `ReportSectionReadModel` carries the section author's display role end-to-end (Prisma → service → mapper → UI gating). Head/Admin viewing `/lead/report?period=X` sees Revoke (not Request Reopen). Closes v7.0 UX-08 / HANDOFF #48.
- [ ] **UX-09** — Recharts `<ResponsiveContainer>` warnings on `/reports/trends` initial mount silenced via `minWidth={0}` sweep. Cosmetic but spammy. Closes v7.0 UX-09.
- [ ] **UX-10** — Risk schema gains `stageName` field end-to-end (Prisma migration with backfill + Zod schema + read model + edit dialog). Unblocks linkedRiskCount confirm-on-Clear path in stage-chip. Closes v7.0 UX-10.
- [ ] **UX-12** — Apple HIG 44px touch-target floor across lead-form action surfaces, via single-source CSS variable. Item/Risk/Decision/Priority dialog Save+Cancel + ChevronLeft/Right nav buttons. Closes v7.0 UX-12.
- [ ] **UX-13** — "0/7 stages" counter regression in Products tab (regressed mid-2026-05-05 session — counter reads stale snapshot, not new `listStages` query). + 3 LOW mockup deltas: DEC-2 `--color-canvas` alias, SDLC-3 locked-stage tooltip with assignee name, LF-1 period nav leading "Week" + calendar icon (or document as intentional skip).
- [ ] **UX-14** — HIST-2 Quick Filters card in lead-history-sidebar (All / Submitted / Drafts pill row, third card after Reporting Overview + Recent Pattern). Filter state lifted to `lead/history` page; passed to `LeadHistoryList` for client-side filter.
- [ ] **UX-15** — Addressable URLs for report views. Currently `/lead/report` and `/head/report` have no identifier in the path — user can't tell which report they're viewing, can't share a link, can't bookmark a specific period. Move to `/lead/report/[reportId]` (and `/head/report/[reportId]`); legacy `/lead/report` 307-redirects to current period's reportId. Period prev/next nav pushes router.push(newReportId) so back/forward works. Browser title updates with weekLabel. Card clicks in /lead/history and /reports/history land on the new pattern. Integration test: deep-link to a non-current period from a fresh tab opens that period (not the current one).

### Security & Audit (Phase 36)

- [ ] **SEC-01** — Rate limiting via `@nestjs/throttler`. Three tiers: auth procedures (login, dev-login) 5/min/IP; mutations 30/min/IP; queries 200/min/IP. `NODE_ENV=test` bumps to 1000/min to keep E2E green. Tests assert 6th rapid login returns 429.
- [x] **SEC-02** — Audit-trail extension to all 26 mutations (admin.* + leadForm.* + period.* + reports.* + reminders.*). Implemented as a tRPC middleware (not per-procedure), capturing {actor, action, target, before/after diff, timestamp}. PII-redacted via existing audit-logger envelope. Visible in /admin (later phase) — for v8.0 just stored as structured log lines.
- [ ] **SEC-03** — Secrets management hardening: env.schema fail-fast in prod (NODE_ENV=production && AUTH_DEV_MODE=true → boot abort), SAML cert pinning verified in startup self-test, no-secret-in-logs assertion test (logger.test.ts greps stringified errors for known secrets).
- [ ] **SEC-04** — CORS prod whitelist (multi-origin via env CSV `FRONTEND_URLS`). CSP tightening (drop `unsafe-inline` for style-src once Tailwind v4 layer is stable; documented carve-out otherwise). Helmet config audit: HSTS, frame-ancestors, no-referrer-when-downgrade.

### Observability (Phase 37)

- [x] **OBS-01** — OTel HTTP middleware + Prisma instrumentation. OTLP/HTTP exporter, env-configurable endpoint (`OTEL_EXPORTER_OTLP_ENDPOINT`), default sampling 0.1, full disable via `OTEL_SDK_DISABLED=true`. Traces visible in Jaeger when dev compose includes the optional Jaeger service.
- [x] **OBS-02** — DLQ alert rule. BullMQ failed-job count > N (configurable, default 5) triggers structured ERROR log + custom Prometheus counter `cr_dlq_failed_total{queue=...}` increments. Counter scraped via `/metrics`.
- [ ] **OBS-03** — Prometheus scrape config (`deploy/prometheus.yml`) targeting `/metrics`. Grafana dashboard JSON skeleton with 4 panels: HTTP request rate, p95 latency, DLQ failed total, login attempts rate. `docker-compose.observability.yml` brings up Prom + Grafana for local validation.
- [ ] **OBS-04** — Log-sink documentation. Vector and Promtail config templates in `deploy/log-sink/`, both consuming the rotated JSON log files. RUNBOOK section explains how to point either at a real Loki/Splunk/Datadog endpoint.

### Infrastructure & Deploy (Phase 38)

- [ ] **INF-01** — Prod migration init-container in `docker-compose.prod.yml`. Runs `prisma migrate deploy` before API service starts; API service `depends_on: { migrate: { condition: service_completed_successfully } }`. `Dockerfile.api` adds `--migrations-only` mode for K8s init-container reuse later. `apps/api/scripts/migrate.sh` wraps it.
- [x] **INF-02** — Caddy reverse-proxy with automatic TLS (Let's Encrypt) + healthcheck integration + WS upgrade for tRPC subscriptions. Fallback to caddy local CA for staging. `deploy/caddy/Caddyfile` + service in `docker-compose.prod.yml`.
- [x] **INF-03** — SAML hardening at docs+mock scope: `docs/keycloak-setup.md` covers SP metadata generation, IdP cert exchange, attribute mapping; `apps/api/src/modules/auth/saml.integration.test.ts` uses `samlify` to mock IdP, asserts cert-pinning + signed-assertion validation + replay-attack rejection. Real Keycloak service deferred to v8.1.
- [ ] **INF-04** — RUNBOOK.md + INCIDENT-PLAYBOOK.md. RUNBOOK covers 10 failure modes (DB down, Redis down, SMTP fail, migration fail, DLQ growth, SAML 500, PDF job stuck, disk full, 5xx spike, TLS expired) each with detect / triage / resolve / escalate. INCIDENT-PLAYBOOK has rollback procedure (revert tag → push → migrate down) and on-call rotation template. README links to both.

### Performance (Phase 39)

- [x] **PERF-01** — PgBouncer service in `docker-compose.prod.yml` (transaction mode, pool=20). Prisma `DATABASE_URL` annotated with `pgbouncer=true&connection_limit=1`. `.env.example` + `env.schema.ts` updated. Prisma migrate-deploy still uses `DIRECT_URL` (bypass pool).
- [ ] **PERF-02** — Turbopack experiment: drop `--webpack` from `apps/web/package.json` dev script. Verify no runaway loop returns (the bug that caused webpack pin is closed). Measure HMR delta and document. Rollback if regression.
- [ ] **PERF-03** — `pg_stat_statements` extension enabled in dev compose. Index audit: capture top 10 slow queries after running E2E suite + a representative load, generate one `CREATE INDEX` migration covering them. `.planning/PERF-AUDIT-2026-05.md` documents methodology + results.
- [ ] **PERF-04** — k6 load test baseline. Scenario: 50 concurrent leads submitting + viewing reports across 5 weeks. Target p95 < 300ms for read paths, p95 < 800ms for submit. `tests/load/k6-baseline.js` + `.planning/LOAD-TEST-2026-05.md` with results table.
