  <action>
    Create a generic, typed `DataTable<T>` component in `packages/ui/src/components/data-table.tsx`.

    **Props interface:**
    ```typescript
    type Column<T> = {
      key: string;
      header: string;
      sortable?: boolean;
      cell?: (row: T) => ReactNode;
      className?: string;
    };

    type DataTableProps<T> = {
      columns: Column<T>[];
      data: T[];
      onRowClick?: (row: T) => void;
      'aria-label'?: string;
    };
    ```

    **Implementation requirements:**
    - Uses shadcn `Table`, `TableHeader`, `TableRow`, `TableHead`, `TableBody`, `TableCell` from the ui/ directory (relative import `./ui/table`)
    - Sort state: `useState<{ key: string; direction: 'asc' | 'desc' } | null>(null)`
    - Clicking a sortable column header toggles asc -> desc -> null (cycle)
    - Sort icon: `ChevronUp` (asc) or `ChevronDown` (desc) from lucide-react, shown next to active sort column header text
    - Active sort column header: `font-semibold` (per UI-SPEC)
    - Header row: `bg-muted` background (per UI-SPEC)
    - Row: `border-b border-border` divider, `hover:bg-muted/50` on hover (per UI-SPEC)
    - If `onRowClick` provided, rows have `cursor-pointer`
    - Client-side sorting: create sorted copy of data array using `Array.prototype.toSorted()` (immutable sort)
    - Support string and number comparison; use `localeCompare` for strings, numeric comparison for numbers
    - Cell rendering: if `column.cell` function provided, call it; otherwise access `row[column.key]` with proper typing
    - **Empty state** (per UI-SPEC Copywriting): when `data.length === 0`, render centered message:
      - Heading: "No data yet" (`text-lg font-semibold text-muted-foreground`)
      - Body: "There are no entries to display. They will appear here once data is available." (`text-sm text-muted-foreground`)
      - Use `TableRow` with a single `TableCell` spanning all columns (`colSpan={columns.length}`)
      - Center the content with `text-center py-12`
    - Add `aria-label` to the `<Table>` element for screen readers
    - Add `aria-sort="ascending"` or `aria-sort="descending"` on the active sort `<TableHead>`

    **Do NOT use TanStack Table** -- per STACK.md research, it is unnecessary overhead for this user count. Plain array sort is sufficient.
