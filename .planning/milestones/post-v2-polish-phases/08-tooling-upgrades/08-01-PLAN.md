1. In `package.json` (root):
   - Change `"packageManager": "pnpm@9.15.0"` to `"packageManager": "pnpm@10.11.0"` (or latest 10.x stable)
   - Change `"engines": { "node": ">=20.0.0" }` to `"engines": { "node": ">=20.19.0" }` (required by ESLint 10 in Plan 02, but set now to avoid double-edit)

2. In `pnpm-workspace.yaml`, add the `onlyBuiltDependencies` allowlist AFTER the `packages` block:

   ```yaml
   packages:
     - apps/*
     - packages/*

   onlyBuiltDependencies:
     - prisma
     - "@prisma/client"
     - playwright
     - esbuild
   ```

   This is required because pnpm 10 blocks lifecycle scripts by default. Without this, `prisma generate` (postinstall) will not run, breaking the Prisma client.

3. Run `corepack prepare pnpm@10.11.0 --activate` to install pnpm 10.

4. Delete all node_modules and reinstall:

   ```bash
   rm -rf node_modules apps/*/node_modules packages/*/node_modules
   pnpm install
   ```

5. Verify the install succeeded by checking that `pnpm --version` shows 10.x and `pnpm turbo build` completes (may fail on Next.js — that is expected and fixed in Task 2).
