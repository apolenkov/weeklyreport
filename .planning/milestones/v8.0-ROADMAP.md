## Overview

v8.0 turns CustomReport from "feature-complete and locally working" into "deployable and operable in production". Every phase closes a real gap audited from the codebase 2026-05-05 — not invented work.

The audit (`.planning/INTERACTION-INVENTORY-2026-05-05.md` + this milestone's research) confirmed the codebase is closer to ready than memory suggested: CI workflow exists, Dockerfiles exist, `/health/*` and `/metrics` endpoints exist, Helmet+CORS-whitelist+structured logging exist. The remaining gaps are concrete and bounded.

**Six themed phases:**

- **Phase 34 — Quality Foundation:** local pre-commit gate, coverage thresholds, ESLint+TS sweeps, Prisma migrate-reset CI gate, DOM-walker / mutation-audit CI integration, push-guard. Slurps v7.0 Phase 33-\* (API Hardening).
- **Phase 35 — UX Polish:** "0/7 stages" counter regression, HIST-2 Quick Filters, role-mapping end-to-end, Recharts + Risk.stageName migration, 44px touch-target single-source, BullMQ DLQ admin UI. Slurps v7.0 Phase 32-\* (UX Polish) + 33-03 (DLQ admin).
- **Phase 36 — Security & Audit:** rate limiting (NestJS throttler), audit-trail extension to all mutations, secrets validation, CORS prod whitelist.
- **Phase 37 — Observability:** OTel HTTP tracing, DLQ alert rule + custom Prometheus counters, Prometheus scrape config + Grafana skeleton, log-sink documentation.
- **Phase 38 — Infrastructure & Deploy:** prod migration init-container, reverse-proxy with auto-TLS (caddy), SAML hardening (docs + samlify-mock test scope), RUNBOOK + incident playbook.
- **Phase 39 — Performance:** PgBouncer prod config, Turbopack experiment, pg_stat_statements + index audit, k6 load test (50 concurrent).

## Key Themes

1. **Close every audited prod-blocker** — rate limiting, prod migrations on-start, RUNBOOK, real CORS whitelist. The "ship-it" gates.
2. **Surface the operational signal we already collect** — DLQ has metrics but no alert; audit logger exists but covers only auth events; Bull Board mounts but has no admin-side detail UI. Make existing infra visible.
3. **Pay down v7.0 debt** — the unexecuted v7.0 backlog is real work (ESLint warnings, TS errors, Risk.stageName) and absorbing it into v8.0 avoids drift.
4. **Preserve quality bar via CI gates** — coverage thresholds, DOM-walker side-effect coverage, mutation-audit black-hole detection, prisma migrate-reset, all in CI. Future regressions get caught automatically.
