           await this.prisma.$queryRaw`SELECT 1`;

         }

       - Injectable class extending `HealthIndicator` from `@nestjs/terminus`

         ```typescript
         import Redis from 'ioredis';
         ```

       - `async isHealthy(key: string)`: calls `await this.redis.ping()`, returns `this.getStatus(key, true)` on success, throws HealthCheckError on failure
       - Implements `OnModuleDestroy` to disconnect Redis client

       - `@Get('ready')` with `@HealthCheck()` decorator:
         - Checks database: `() => this.prismaHealth.isHealthy('database')`
