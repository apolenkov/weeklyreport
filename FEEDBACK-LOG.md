## Как разбираем в финале (по команде «хватит»)

Три источника сводятся в один отчёт:

1. Пункты пользователя из этого файла.
2. Ошибки приложения — `apps/api/.logs/app.log` (`pnpm logs:errors`).
3. Bugsink — `http://localhost:8000` (Sentry-совместимый, фронт + бэк ошибки).
4. Loki / otel-lgtm — `pnpm observability:logs`.

Финал: доработки по приоритету + находки логов, со связкой жалоба ↔ ошибка.
