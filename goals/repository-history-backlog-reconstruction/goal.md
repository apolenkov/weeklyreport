# Goal

Reconstruct the complete locally available CustomReport history into a
source-bound master registry and decision-ready roadmap, following the approved
[facts](./facts.md) and [execution plan](./plan.md).

Completion requires:

- zero unaccounted discovered sources;
- zero substantive owner events without exactly one terminal disposition;
- zero actionable product or process records without source links, an
  evidence-calibrated status, a next action, and a measurable acceptance
  condition;
- all deterministic reconstruction validators passing;
- an independent Sol/high review approving semantic fidelity, status
  calibration, contradiction handling, roadmap coherence, and authority
  boundaries;
- every unavailable required Air source remaining explicitly recorded, with no
  claim of cross-machine completeness while any such source is inaccessible.

Writes are limited to this reviewed goal package and a new dated directory
under `/Users/wrk/work/customreport-archive/`. Product code, OpenSpec, Git refs,
the canonical backlog, runtime systems, credentials, and external systems are
read-only and must not be changed.

Stop and ask the owner only if completion would require new authority, a
credential operation, destructive or external writes, or a missing source whose
absence prevents an honest locally scoped result.
