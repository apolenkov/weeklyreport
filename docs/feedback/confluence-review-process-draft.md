# Процесс ревью еженедельных отчётов

Эта страница описывает, как смотреть еженедельный отчёт группы и давать по нему
обратную связь, не блокируя период. Если у вас есть замечания к самому процессу —
оставьте комментарий внизу страницы.

## Кто что может

| Вы              | Посмотреть отчёт | «Ознакомлен» | Комментарий к записи | Вернуть секцию на доработку | Залочить период |
| --------------- | :--------------: | :----------: | :------------------: | :-------------------------: | :-------------: |
| Лид             |   свою секцию    |      —       |          —           |              —              |        —        |
| Вьюер (обычный) | ✓ (своя группа)  |      ✓       |          —           |              —              |        —        |
| Вьюер-ревьюер   |        ✓         |      ✓       |          ✓           |              ✓              |        —        |
| Хед             | ✓ (своя группа)  |      ✓       |          ✓           |              ✓              |        ✓        |
| Админ           |     ✓ (все)      |      ✓       |          ✓           |              ✓              |        ✓        |

**Ревьюер** — это не отдельная роль, а право, которое выдаётся на конкретную
группу. Ревьюером может быть и хед (по своей группе — автоматически), и вьюер,
которому это право выдали.

## Как дать обратную связь

1. **Откройте отчёт группы** за текущий период. По умолчанию видно только то, что
   **сдано** (засабмичено); переключатель показывает всё, включая черновики.
2. **Ознакомьтесь.** Кнопка «Ознакомлен» отмечает, что вы видели отчёт — так в
   команде видно, кто уже посмотрел.
3. **Прокомментируйте конкретную запись.** Замечание крепится к конкретному
   пункту (item / риск / решение), чтобы автор сразу видел, **где именно** правка,
   а не искал по всему отчёту.
4. **Вынесите вердикт по секции лида:**
   - **Принято** — секция остаётся сданной (можно с комментариями — это «мягкая»
     обратная связь).
   - **Нужны правки** — секция **автоматически возвращается лиду на доработку**
     (из «сдано» в «черновик»). Лид видит это у себя сразу, вместе с вашими
     комментариями, правит и сдаёт заново.

## Что ревью НЕ делает

- **Не лочит период.** Вернуть секцию на доработку и залочить весь период — разные
  вещи. Залочить (опубликовать) период может только хед. Ревью — это сигнал, а не
  закрытие отчёта.
- **Не дублирует информацию.** Комментарии показываются рядом с самой записью, с
  именем ревьюера; текст записи не повторяется.
- **Не шлёт писем.** Пока всё происходит внутри приложения (in-app); уведомления в
  Telegram/почту — на будущее.

## Частые вопросы

- **Я вьюер — почему не могу оставить вердикт?** Вердикт и комментарии доступны
  только назначенным ревьюерам. «Ознакомлен» доступен всем. Чтобы стать ревьюером
  группы — попросите админа выдать право.
- **Вернул секцию, а она пропала из вида.** По умолчанию показывается только
  сданное; вернувшаяся секция теперь черновик. Переключите вид на «все», чтобы
  следить за доработкой.
