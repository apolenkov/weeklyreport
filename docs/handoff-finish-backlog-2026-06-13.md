## Среда

- Стенд: `pnpm dev` → web :3000, api :3002. Dev-login включён.
- БД disposable (MVP-правило), reseed со штатным Prisma-consent.
- **Пуш в main блокируется auto-mode предохранителем.** Рабочий путь: ветка →
  `git push -c credential.helper='!gh auth git-credential' origin <branch>` →
  `gh pr create` → мёрдж делает пользователь (или `gh pr merge` с его словом).
- Недельный лимит: полный марафон ≈ 8.7M токенов — не гонять без нужды.
- Снапшот `product-accordion.test.tsx.snap` — предсуществующая модификация, не
