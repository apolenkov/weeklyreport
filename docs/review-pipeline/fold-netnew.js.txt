const SCHEMA = {
  type: "object",
  required: ["changeId", "validated", "folded"],
  properties: {
    changeId: { type: "string" }, validated: { type: "boolean" },
    folded: { type: "boolean", description: "true if the finding was added; false if verified already-covered/not-real" },
    notes: { type: "string" },
  },

phase("Fold");
const results = await parallel(
  TARGETS.map((t) => () =>
    agent(
      `Fold a NET-NEW review finding into the EXISTING OpenSpec change openspec/changes/${t.id}/.
First VERIFY the finding against the real code (it is a candidate, not gospel). If real and not
already covered by this change's current artifacts, ADD a requirement + GIVEN/WHEN/THEN scenario

one; SHALL on first body line; every requirement has a scenario), a short design note, and a
task in tasks.md. If already covered or not real, do NOT edit — set folded:false and explain.

FINDING: ${t.finding}
HOW TO FOLD: ${t.fix}

Repo conventions: Russian only a bug in apps/web JSX; ComingSoon intentional; single init
migration intentional (MVP); English-only prod UI intentional; never tell impl to run pnpm
lint:md. Edit OpenSpec ARTIFACTS only — no product code, no tasks marked done.

      { label: `fold:${t.id}`, phase: "Fold", model: t.model, effort: "high", schema: SCHEMA },
