## Постоянные правила

- **Пилот 5–8 находок** перед допуском любого нового вендора к партиям.
- **P10 refutation parity:** «опровергнуто» засчитывается только после
  встречной проверки другим исполнителем. Трижды спасало реальные баги.
- **Scope-guard + echo-back-guard включены с первой партии** (`.claude/scripts/check-lane-scope.mjs`,
  `.claude/templates/codex-implement-preamble.md`).
- **P4 красный слайс:** зелёные соседи коммитятся, красный уходит в
  ревью-онли; партию не перезапускать.
- **Гейт-тиры P2:** полный гейт обязателен для L-швов, api non-test,
  prisma, packages/shared.
- Внешние CLI-запуски (grok/codex) — только из главного шелла через
  run_in_background; никогда `&` в foreground и никогда изнутри сабагентов.

## Верификация (выжимка)

- Коды возврата: `sh -c '<cmd>; echo EXIT=$?'` — никогда через пайп.
- Ground truth только `rtk proxy`; vitest в rtk не заворачивать.
- «Сделано» = после независимой проверки (fetch/повторное чтение).
- Закрытие кампании: пофайловые независимые грейдеры + аудитор
  распределения на каждый транш; размер выборки — по change, не по удобству.
- Общий worktree: объявлять полосы; долгие прогоны не совмещать с мутацией
  node_modules; при лежащем линте вести явный список «перелинтовать позже».
- Ручная архивация change: tasks → validate → **sync delta specs** → mv → commit.
